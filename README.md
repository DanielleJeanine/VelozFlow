# VelozFlow
Projeto desenvolvido para apresentação no processo seletivo **Coding Tank — Ada Diversidade 2026**.  **VelozFlow** é uma proposta de solução para a empresa fictícia VelozMart, utilizando estruturas de dados Heap e duas filas de prioridade para otimizar a organização e a expedição de pedidos, considerando prazos, prioridades e capacidade logística.
