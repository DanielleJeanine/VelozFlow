# 🚀 VelozFlow — Priorização Inteligente de Pedidos

### 📦 Uma solução para tornar a expedição logística mais organizada, eficiente e orientada por prioridades.


## 📌 Sobre o projeto

O **VelozFlow** é uma proposta de solução desenvolvida para o processo seletivo **Coding Tank — Ada Diversidade 2026**.

O projeto apresenta uma estratégia de organização e priorização de pedidos para a empresa fictícia **VelozMart**, utilizando estruturas de dados do tipo **Heap (fila de prioridade)**.

A proposta busca otimizar a ordem de expedição, considerando fatores como prazo, pontuação de prioridade, tamanho dos pedidos e disponibilidade das docas.

Mais do que organizar uma fila, o objetivo é demonstrar como estruturas de dados e algoritmos podem apoiar decisões logísticas.

---


## 💡 Nossa solução:

O VelozFlow propõe a utilização de **duas filas de prioridade**, implementadas conceitualmente com Heaps de Múltiplas Chaves.

Além da entrega do PDF com a proposta, também foi gerado um simulador HTML, permitindo visualizar a organização e a seleção dos pedidos.


---

## 🛠️ Conceitos abordados

- Estruturas de dados: Heap e filas de prioridade.
- Algoritmos de ordenação e seleção por prioridade.
- Análise de complexidade assintótica — Big O.
- Regras de negócio e critérios de desempate.
- Simulação de cenários logísticos.
- Avaliação de desempenho e trade-offs.
